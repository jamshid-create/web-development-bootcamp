### Random Number Generation

### Control Statements & Logic

* How to use `if` and `else` statements
* How conditional statements control the flow of a program
* How to combine conditions using logical operators

### Comparators & Equality

* Equality: `===`
* Not equal: `!==`
* Greater than: `>`
* Less than: `<`
* Greater than or equal to: `>=`
* Less than or equal to: `<=`
* The difference between `===` and `==`
* How `===` also checks the data type

### Logical Operators

* AND: `&&`
* OR: `||`
* NOT: `!`

### Arrays

* How to create and work with JavaScript arrays
* How to add elements using `.push()`
* How to remove elements using `.pop()`
* How to work with arrays in programming challenges

### While Loops

* How to create and use `while` loops
* How to use loops to repeat code while a condition is true

### For Loops

* How to create and use `for` loops
* How to use `for` loops to repeat code a specific number of times
