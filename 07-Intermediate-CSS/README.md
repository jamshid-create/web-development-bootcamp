# 07 - Intermediate CSS

## 📚 Topics Covered

* CSS Cascade
* Specificity and Inheritance
* Combining Selectors
* CSS Positioning
* CSS Flag Project

## 🧩 Projects

### 7.3 - CSS Flag Project

A project created to practice CSS positioning, selectors, and styling by recreating the flag of Laos with CSS.

## 💡 What I Learned

* How competing CSS styles are resolved using the CSS cascade
* The four broad concepts involved in resolving competing styles: position, specificity, type, and importance
* How CSS specificity is prioritized:

  * ID selectors
  * Attribute selectors
  * Class selectors
  * Element selectors
* The different ways CSS can be applied:

  * Inline
  * Internal
  * External
* How the `!important` rule affects the priority of a CSS declaration
* How inheritance works in CSS
* How to target specific elements using combining selectors
* How to use group selectors
* How to target direct children using the child combinator
* How to target descendants using the descendant combinator
* How to chain selectors to target elements that match multiple selectors
* How to combine different CSS combinators
* How to use `static`, `relative`, `absolute`, and `fixed` positioning
* How to use the `z-index` property to control the stacking order of positioned elements
* How to apply CSS concepts to recreate the flag of Laos
