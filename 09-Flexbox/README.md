## 🧩 Projects

### 9.4 - Flexbox Pricing Table Project

A project created to practice Flexbox by building a responsive pricing table layout.

## 💡 What I Learned

* What Flexbox is and how it works
* How to use `display: flex`
* How Flexbox can be used to create flexible layouts
* How to create row and column layouts using `flex-direction`
* How to control the layout using:

  * `justify-content`
  * `align-items`
  * `align-content`
* How to use `flex-wrap` to control whether flex items wrap onto multiple lines
* How to control the order of flex items using the `order` property
* How Flexbox sizing works, including shrinking and growing
* The relationship between content width, `width`, `flex-basis`, and `min-width` / `max-width`
* How to use Flexbox in practice to build a pricing table
