## 🧩 Projects

### 10.3 - Mondrian Project

A project created to practice CSS Grid by recreating a Mondrian-style painting.

## 💡 What I Learned

* What CSS Grid is and how it works
* How CSS Grid provides a two-dimensional layout system
* The difference between Flexbox and Grid:

  * Flexbox is mainly used for one-dimensional layouts
  * Grid is mainly used for two-dimensional layouts
* How to size columns and rows using:

  * Fixed sizes
  * Auto sizes
  * Fractional sizes
  * `minmax()`
  * `repeat()`
* How to place and arrange items within a grid
* The main concepts of CSS Grid:

  * Grid lines
  * Grid tracks
  * Grid cells
  * Grid container
  * Grid items
* How `grid-column` is a shorthand for `grid-column-start` and `grid-column-end`
* How to use the `grid-area` property
* How to use CSS Grid to recreate a Mondrian-style painting
