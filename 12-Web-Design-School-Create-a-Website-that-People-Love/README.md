## 📚 Topics Covered

* Introduction to Web Design
* Colour Theory
* Typography
* User Interface (UI) Design
* User Experience (UX) Design
* Web Design in Practice

### 1. Introduction to Web Design

* Introduction to the principles and fundamentals of web design

### 2. Understanding Colour Theory

* The predominant colours:

  * Red
  * Blue
  * Green
  * Yellow
  * Purple
* How to combine colours effectively
* What analogous colours are
* What complementary colours are

### 3. Understanding Typography and How to Choose a Font

* The two large font families:

  * Serif
  * Sans-serif

### 4. Manage Attention with Effective User Interface (UI) Design

* How to create visual hierarchy using:

  * Colour
  * Size
* The importance of layout
* The importance of alignment
* How white space affects a design
* Designing for the target audience

### 5. User Experience (UX) Design

* The importance of simplicity
* The importance of consistency
* Understanding reading patterns:

  * F-pattern
  * Z-pattern
* Designing for different platforms
* Using design skills responsibly

### 6. Web Design in Practice

* Applying the principles of colour theory, typography, UI design, and UX design in practice
