## 🧩 Projects

### 8.4 - Web Design Agency Project

A project created to practice advanced CSS concepts by building a simple responsive website for a web design agency.

## 💡 What I Learned

* How the `block`, `inline`, and `inline-block` display values work
* How to use `display: none` to hide elements
* How to wrap text around elements using `float`
* How to use the `clear` property to control the behavior of floated elements
* What responsive web design is and why it is important
* How to make websites look good on different screen sizes
* The four main approaches to building responsive websites:

  * Media queries
  * CSS Grid
  * CSS Flexbox
  * External frameworks such as Bootstrap
* How media queries are used to create responsive layouts
* How to add breakpoints for different screen sizes
* How to build a simple website for a web design agency
