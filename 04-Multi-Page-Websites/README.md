## 💡 What I Learned

* How to work with absolute and relative file paths
* How to use special characters such as `..` and `.`
* How to create and link multiple webpages such as Home, About, and Contact
* What `<!DOCTYPE html>` does and how it specifies HTML5
* The purpose of the `<html>` element as the root of the document
* How to use the `lang` attribute to specify the language of the text content
* The purpose of the `<head>` element and the information placed inside it
* How `<meta charset="UTF-8">` specifies the character encoding of a webpage
* How to use the `<title>` element to define the webpage title
* The purpose of the `<body>` element and where the website content is placed
* How to build a portfolio website to showcase the work learned so far
* What web hosting is and how to put a website online using GitHub
* How to build projects independently through Capstone Projects
