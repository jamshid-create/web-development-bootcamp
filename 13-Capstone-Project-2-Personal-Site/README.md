# 13 - Capstone Project 2 - Personal Site

## 🧩 Project

A personal website built to showcase skills, experiences, interests, projects, and background using HTML and CSS.

## 📋 Project Requirements

* Build the website entirely with HTML and CSS
* Create a hero section with a brief introduction
* Include a resume section with education, experience, skills, and other relevant information
* Showcase previous projects or work
* Include an About Me section
* Include a Contact Me section
* Use valid HTML and semantic markup
* Use valid CSS with proper naming conventions and organization
* Make the website responsive across different screen sizes and devices
* Use appropriate `alt` text for images

## 📁 Deliverables

* One HTML file for the website structure
* One CSS file for styling
* Additional assets such as images when needed

## 🎯 Project Goal

To create a visually appealing and easy-to-navigate personal website that showcases skills, experiences, interests, and projects using HTML and CSS.
